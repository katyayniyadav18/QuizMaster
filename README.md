
🎯 QuizMaster – Interactive Quiz Web App

«A modern, responsive and interactive quiz application built using HTML, CSS and JavaScript.»

QuizMaster is a browser-based quiz application designed to make learning more interactive and engaging. Users can answer multiple-choice questions, manage their time, receive instant feedback, and view their final score.

✨ Features

- 🎯 Interactive multiple-choice questions
- ⏱️ 15-second timer for each question
- 📊 Automatic score calculation
- ✅ Correct answer highlighting
- ❌ Incorrect answer highlighting
- 📈 Question progress indicator
- 🏆 Final score and performance message
- 🔄 Restart / Play Again functionality
- 📱 Responsive design for different screen sizes
- 🎨 Modern dark-themed user interface
- ⚡ Fast and lightweight — no external backend required

🎮 How to Use

1. Open the Live Demo.
2. Click Start Quiz.
3. Read each question carefully.
4. Select your answer before the timer ends.
5. Click Next Question.
6. Continue until all questions are completed.
7. View your final score.
8. Click Play Again to restart the quiz.

---

🧠 How the Application Works

The quiz questions and answers are stored in "questions.js".

JavaScript handles the main functionality of the application, including:

- Loading questions
- Displaying answer options
- Starting and controlling the timer
- Checking selected answers
- Calculating the score
- Updating the progress bar
- Moving between questions
- Displaying the final result

The HTML provides the structure, while CSS creates the visual design and responsive layout.
