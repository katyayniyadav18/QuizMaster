🎯 QuizMaster – Interactive Quiz App

QuizMaster is a modern and responsive interactive quiz application built using HTML, CSS, and JavaScript.

The application allows users to answer multiple-choice questions, track their score, and complete a timed quiz through a simple and attractive interface.

🚀 Features

- Multiple-choice quiz questions
- 15-second timer for each question
- Automatic score calculation
- Correct and incorrect answer highlighting
- Progress bar
- Final score screen
- Restart quiz functionality
- Responsive design
- Modern dark-themed interface
- Beginner-friendly JavaScript implementation

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Git & GitHub

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run it using Live Server or open the file directly in a web browser.
5. Click Start Quiz.

🧠 How It Works

The questions are stored inside "questions.js".

JavaScript controls:

- Question loading
- Answer selection
- Timer
- Score calculation
- Progress tracking
- Result generation
- Quiz restart

🎨 UI

QuizMaster uses a dark modern interface inspired by popular streaming platforms.

The layout is responsive and works on both desktop and mobile screens.
